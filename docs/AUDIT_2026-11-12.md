# Fastfingaz repository audit

12 November 2026 · through v0.4.3

## Fixed

- The live popup gets its reading from the active ChatGPT tab. The service worker writes text-free reload snapshots to trusted session storage, scoped to the tab and page path.
- Settings, session writes and history deletion use one queue. The worker checks the current text opt-in before it writes a record. Export reads settings, sessions and history together.
- Manual breaks are removed before the gap cap. Saved start and end timestamps reflect when the run happened. Editing after a failed send cancels the pending send. A temporarily hidden composer keeps its tracker.
- Clearing history refreshes the badge. Settings and history deletion surface write failures. The options page shows the actual 16-character minimum.
- The popup uses native scrollbar styling with a fallback for older supported Chrome versions. Idle HUD ticks avoid repeating identical paints.
- The site preview returns a 400 for malformed paths, and the site build keeps editorial sources and generation notes out of its public output. The production footer, social art and store popup capture use the correct domain.
- Vitest moved to the patched 4.1 line. The existing tests cover the changed pause math.
- Three original ImageGen editorial studies are available with exact prompts and provenance in [the art notes](art/social/PROMPTS.md).

## Fixed in v0.4.3

- A new opt-in prompt that exceeds Chrome's byte quota can no longer silently prevent the reading from saving. The worker retries with metrics alone and preserves older opted-in text. If even the metrics cannot be written, the receipt says the reading is unsaved and offers the usual share action.
- Long runs fill the cadence chart across the full duration. Finished receipts and landscape cards keep the early samples when fitting the chart into fewer bars. The live HUD continues to show the latest bars.
- The extension skips unrelated editable elements that previously matched the positional fallback. Recognised editor selectors still work. Generic editors need a send button in the same form.
- Share format buttons report their pressed state. History refreshes preserve the selected format, the Back button restores keyboard focus, and the HUD receipt timeout pauses while the share sheet is open. Session detail identifies readings whose exports include prompt text. The idle slider persists when the user commits a change.
- The site build generates its PNG icon set from a single source. Published filenames are preserved. Removed stale roadmap entries for reopening and copying cards.
- The card demo falls back to all formats for unknown format values. Regenerated the three sample cards and updated the public method description to match the current export and popup.
- Added three campaign studies with exact prompts. The square keycap tray, landscape receipt dispenser and portrait typing desk are available in [the art notes](art/social/PROMPTS.md).

## Experience improvements to consider

2. Put short Think WPM, Flow WPM and signal explanations beside the first receipt so the numbers are understandable without opening the method page.
3. After calibration, add a weekly recap card and a badge choice for today's Think WPM, Flow WPM or no badge.
4. Capture one real HUD-to-receipt session for the store listing and test the share controls with a screen reader.
