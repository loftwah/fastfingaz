# Fastfingaz repository audit

12 November 2026 · v0.4.2

## Fixed

- The live popup gets its reading from the active ChatGPT tab. The service worker writes text-free reload snapshots to trusted session storage, scoped to the tab and page path.
- Settings, session writes and history deletion use one queue. The worker checks the current text opt-in before it writes a record. Export reads settings, sessions and history together.
- Manual breaks are removed before the gap cap. Saved start and end timestamps reflect when the run happened. Editing after a failed send cancels the pending send. A temporarily hidden composer keeps its tracker.
- Clearing history refreshes the badge. Settings and history deletion surface write failures. The options page shows the actual 16-character minimum.
- The popup uses native scrollbar styling with a fallback for older supported Chrome versions. Idle HUD ticks avoid repeating identical paints.
- The site preview returns a 400 for malformed paths, and the site build keeps editorial sources and generation notes out of its public output. The production footer, social art and store popup capture use the correct domain.
- Vitest moved to the patched 4.1 line. The existing tests cover the changed pause math.
- Three original ImageGen editorial studies are available with exact prompts and provenance in [the art notes](art/social/PROMPTS.md).
