# Fastfingaz mark study

Shipped in v0.4.0 as Fastfingaz. The live icons come from the Pixel F study in
`docs/brand/fastfingaz/`. The direction is in `docs/BRAND.md`.

## Files

- `board.png` — the full study: three marks at 128/48/32/16, the wordmark and a 12-inch sleeve mock.
  Source: `demo/brand-board.html`.
- `icon-pixel-f.svg` + PNGs at 16/32/48/128/512 — **recommended primary mark.** A sampler-pad F;
  keeps the current pixel-grid language and survives 16px.
- `icon-four-fingers.svg` + PNGs — secondary mark. Four fingers and a VU meter; reads as an
  equalizer at small sizes.
- `icon-white-label.svg` + PNGs — sleeve/OG mark. The inner detail collapses at 16px; do not use it
  for the toolbar.

## Recommendation

Use **Pixel F** for the app icon, favicon, toolbar and store icon. Use **Four Fingers** as the
cadence/secondary mark. Keep **White Label** for the sleeve, OG and merch.

The wordmark is `FASTFINGAZ` in Geist Pixel. No new font is needed; it is already bundled.
