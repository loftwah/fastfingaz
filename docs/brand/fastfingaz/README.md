# Fastfingaz icon set (staged)

Approved mark: **Pixel F**, shipped in Fastfingaz v0.4.0. These files are the source of truth for
the extension, site and store icons.

| File | Destination |
| --- | --- |
| `icon-16.png` | `public/icon/16.png` |
| `icon-32.png` | `public/icon/32.png` |
| `icon-48.png` | `public/icon/48.png` |
| `icon-128.png` | `public/icon/128.png` and `site/icon-128.png` |
| `icon-192.png` | `site/icon-192.png` |
| `icon-512.png` | `site/icon-512.png` |
| `icon-180.png` | Apple touch icon |
| `maskable-192.png` | `site/manifest.webmanifest` maskable icon |
| `maskable-512.png` | `site/manifest.webmanifest` maskable icon |
| `favicon.svg` | `site/favicon.svg` |

The mark is a black rounded square with the orange pixel F. It has a generous safe margin, so the
maskable versions use the same art. Re-render from `favicon.svg` if the mark changes.

No image model was used. The vector is the source of truth.
