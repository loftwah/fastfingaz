# Fastfingaz v0.4.3

- When a new opt-in prompt exceeds the storage quota, Fastfingaz retries with metrics alone and tells you on the receipt. If saving still fails, you can share the unsaved receipt to keep a copy.
- Cadence charts cover the whole run, including long prompts.
- The popup keeps your share format when history changes. The card format buttons announce which option is selected, and Back restores focus to the session. The HUD keeps the share sheet open while you choose or download a card.
- Composer detection ignores unrelated editors that lack a recognised ChatGPT identifier or a matching send control in their form.
- The extension keeps its existing Chrome permissions and local history.

Download the ZIP, extract it, and select the extracted folder via **Load unpacked** on `chrome://extensions`. For an existing unpacked install, replace the files in its existing folder and click **Reload** to keep its extension ID and history.
