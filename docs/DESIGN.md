# Thinktype design notes

The product is a measurement instrument, not a productivity coach. The design should feel like a
well-made gauge that happens to live in ChatGPT: quiet, precise, a little bit alive.

## Brand

- **Name:** Thinktype. Lowercase wordmark, uppercase small labels.
- **Line:** "Your real typing speed, while you're actually thinking."
- **Voice:** dry, precise, never scolding. Numbers are a mirror, not a scoreboard.
- **Mark:** a geometric uppercase `T` in a gradient `lime → teal`, with a small violet cursor dot.
  At 16px the T still reads. The dot is the "typing" half of the idea.

### Palette

| Token | Dark | Light | Use |
| --- | --- | --- | --- |
| ink | `#08090b` | `#f6f7f9` | page background |
| panel | `#101216` | `#ffffff` | cards |
| text | `#f2f4f7` | `#101216` | primary text |
| muted | `#8a9099` | `#6b7280` | labels, secondary copy |
| lime | `#c9f75b` | `#4d7c00` | flow, primary accents, CTA |
| violet | `#9b8cff` | `#6d5bd0` | think, pauses |
| teal | `#5eead4` | `#0f766e` | sparkline end, secondary accent |

Semantics matter: **violet = thought**, **lime = hands**. Think is violet on the receipt, flow is
lime. The share card uses the same rule.

### Type

- UI: system sans (`-apple-system`, Segoe UI, Inter, Helvetica).
- Numbers: `ui-monospace, SFMono-Regular, "SF Mono", Menlo, monospace`, tabular numerals, tight
  tracking. The instrument look lives here.
- Small labels: 9–10px, 600–700 weight, `0.14–0.2em` tracking, uppercase.

## HUD

300 × 162px glass card, top-right by default. Lives in a shadow root so ChatGPT's CSS cannot touch
it. Draggable by the header, collapsible to a 58px orb.

Anatomy:

1. **Header** — status dot, `THINKTYPE`, collapse and hide.
2. **Readout** — live 5s flow WPM in 46px gradient mono, timer and word count on the right.
3. **Sparkline** — rolling cadence, 2px gradient stroke with a soft area fill.
4. **Footer** — state word (typing / thinking / waiting) and the current think/flow pair.
5. **Receipt** — replaces the readout after send: think, flow, words, signal, **Copy card**.
6. **Orb** — collapsed state. Still shows live WPM; a teal ring means a receipt is waiting.

States:

- `idle` — muted dot, "ready", "waiting for input".
- `typing` — lime dot, "live flow", number active.
- `thinking` — violet breathing dot, number dimmed to 55%, sparkline holds its shape.
- `receipt` — teal dot, receipt panel, border warms to lime, auto-dismisses after 20s.

Motion is limited to a breathing status dot, a 220ms receipt rise, and short hover transitions.
`prefers-reduced-motion` disables all of it. The HUD never steals focus or blocks the composer.

## Share card

1200 × 630, rendered at 2× on canvas. Dark-only: it is the brand.

- Background `#07080a` with violet and lime radial glows, a 26px dot grid at 4.5% opacity, 28px
  radius and a hairline border.
- Header: T mark, `thinktype`, date tracked out on the right.
- Hero: `THINK WPM` label, 172px gradient mono number, `wpm`, the definition in plain language, and
  a violet-dot insight chip: `21% thinking overhead`.
- Right column: `FLOW` (78px lime) and `PEAK` (52px), then words / time / signal.
- Sparkline: 576 × 62, lime stroke with a 16px glow and a fading area fill.
- Footer: "Composed in ChatGPT" and the repo URL.
- A paste-dominant session gets an amber `PASTED · LOW SIGNAL` pill instead of hiding the data.

The card is generated locally by `src/shared/share-card.ts`. No image service, no text upload.
`Copy card` writes a PNG to the clipboard and falls back to a download.

## Popup

380px wide. Today's think/flow pair is the hero, followed by a 14-day bar chart and the last 8
sessions. A session opens into a detail view with the live card preview, stats, and copy/download
actions. The popup uses the same palette and number treatment as the HUD.

## Options

A calm reading page rather than a settings wall: numbered sections, one idea per card, hints written
in plain language. Privacy is a first-class section, not a footnote.

## Artwork placeholders

Everything in `docs/art/` is a placeholder produced from the real components, not final marketing
art. Replace when the brand is locked:

- `hero.png` — README hero, 1280×960 composition (headline, HUD, card).
- `hud.png` — HUD close-up on a dark field.
- `share-card.png` — 1200×630 card.
- `social-preview.png` — GitHub social preview, 1280×640 (to be supplied).
- `icon.svg` — source mark; PNG sizes are generated by `npm run icons`.

Do not bake UI copy into the artwork. Keep the card renderer as the source of truth for cards.
