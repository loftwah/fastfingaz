# Fastfingaz v0.4.1 — one instrument by default

The baseline rail is now **off by default**, so the HUD is the only display on ChatGPT.

## What changed

- The companion baseline rail used to appear at wide widths and repeat LAST / BEST / AVG beside the
  HUD. It is now **opt-in**.
- Settings → HUD → **Show the baseline rail** brings back the 14-day think WPM chart, best/avg flow,
  readings/drafts and the last four sessions.
- The live HUD, the four HUD sizes, the paper receipt and the three share cards are unchanged.
- No new permissions, no network code, prompt text still opt-in. 47 tests.

## Upgrade note

The setting defaults to off for existing users too, so after updating the extra panel disappears
without touching your history.

## Install

Reload the `unpacked` folder in `chrome://extensions`, then refresh ChatGPT. The version should read
**0.4.1** and the HUD should read `FASTFINGAZ` / `FF-02`.
